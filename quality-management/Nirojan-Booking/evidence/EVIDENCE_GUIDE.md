# Booking Module – Evidence Collection Guide (SE3110)

This directory holds test execution artifacts, logs, and screenshots required for SE3110 grading and viva presentation.

## Recommended Evidence Artifacts to Store Here:

1. **`01_booking_request_creation.png`** – Screenshot of renter booking creation with calculated rental days and total amount.
2. **`02_owner_accept_reject.png`** – Screenshot of owner reviewing incoming booking requests and confirming them.
3. **`03_pickup_qr_code.png`** – Screenshot of the generated pickup QR code displayed in the mobile app.
4. **`04_qr_scanner_handover.png`** – Screenshot of the owner scanning the QR code and successful status transition to `Active`.
5. **`booking_test_execution.log`** – Saved terminal output from running `python test_booking.py`.
